🌐 1. Jaringan Komputer & Internet

🖥️
Definisi

Jaringan Komputer

Sekumpulan perangkat komputer yang saling terhubung satu sama lain melalui media transmisi sehingga dapat saling berbagi data, informasi, dan sumber daya.

🌍
Definisi

Internet

Jaringan komputer global yang menghubungkan jutaan komputer di seluruh dunia secara bersama-sama.

📦
Proses Pengiriman

Paket Data & Alamat IP

Saat mencari video di YouTube, permintaan dikirim ke server web dalam bentuk paket data yang ditujukan ke Alamat IP server web.

🔀 2. Perangkat Jaringan Utama

📡
Perangkat 1

Router

Perangkat jaringan yang bertugas mencari jalur atau rute tercepat dalam pengiriman paket data di internet.

🔌
Perangkat 2

Switch

Perangkat keras yang berfungsi menghubungkan beberapa komputer dalam satu jaringan lokal (LAN).

💬 3. Aplikasi Komunikasi TIK

📱 Pesan Instan (Instant Messaging)

Layanan untuk mengirim pesan teks, foto, audio, atau video secara langsung dan instan kepada pengguna lain.

Contoh Aplikasi: WhatsApp, Telegram, Line.

📧 Surat Elektronik (E-Mail)

Aplikasi komunikasi untuk mengirim surat secara digital/elektronik yang memiliki struktur formal (seperti ada subjek dan isi pesan) mirip surat pos.

Contoh Layanan: Gmail, Yahoo! Mail.

🔑 4. Komponen Kata Sandi (Password) yang Kuat

Karakteristik & Syarat Password Kuat

Kata sandi yang kuat bertujuan menjaga keamanan akun dari peretas (hackers):

  • Jumlah Karakter: Terdiri dari minimal 8 karakter.
  • Kombinasi Karakter: Gabungan dari huruf kapital, huruf kecil, angka, dan simbol.
  • Prinsip Utama: Mudah diingat oleh pemiliknya, tetapi susah/sulit ditebak oleh orang lain.
  • Hindari: Nama pribadi, tanggal lahir, angka berurutan (misal: 12345678), atau kata sandi yang terlalu pendek/lemah.

🛡️ 5. Keamanan Digital & Proteksi Data Pribadi

🔒 Cara Melindungi Data Pribadi

  • Membuat kata sandi yang kuat dan tidak membagikannya ke orang lain.
  • Tidak menyebarkan nomor telepon, alamat rumah, atau identitas pribadi di media sosial.
  • Gunakan aplikasi resmi dan selalu diperbarui.

⚠️ Phishing & Link Mencurigakan

Phishing adalah kejahatan digital berupa penipuan untuk mencuri data pribadi/kata sandi dengan menyamar sebagai pihak resmi melalui tautan (link) palsu.

Jangan mengeklik link sembarangan karena dapat mengandung malware atau phishing!

📶 Bahaya Wi-Fi Publik

Hindari menggunakan jaringan Wi-Fi publik di tempat umum tanpa pengamanan untuk mencegah pencurian data pribadi oleh peretas.

🔄 6. Cara Kerja Pengiriman Data di Internet

⌨️

1. Permintaan

Pengguna mencari data/video di internet.

📦

2. Paket Data

Permintaan diubah jadi paket data ber-Alamat IP Server Web.

📡

3. Router & Switch

Router cari rute tercepat, Switch hubungkan jaringan lokal.

💻

4. Diterima

Paket data sampai di tujuan dan ditampilkan di layar gawai.
