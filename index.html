🎯 Tujuan Pembelajaran

Memahami tiga elemen utama penyusun komputer: Perangkat Keras (Hardware), Perangkat Lunak (Software), dan Pengguna (Brainware).

🧩 3 Elemen Utama Sistem Komputer

🖥️
1. Hardware

Perangkat Keras

Seluruh komponen fisik komputer yang dapat dilihat, disentuh, dan dipindahkan secara langsung.

⚙️
2. Software

Perangkat Lunak

Program dan sistem operasi yang mengontrol dan mengelola seluruh sumber daya perangkat keras.

👨‍💻
3. Brainware

Pengguna Komputer

Manusia yang bertugas mengoperasikan, mengendalikan, dan memanfaatkan perangkat komputer.

⌨️ Perangkat Input

Fungsi

Memasukkan data dan memberikan perintah ke dalam sistem komputer untuk diproses.

Ketukan & Sentuhan

Keyboard, Mouse, Touchpad, Layar Sentuh.

Suara & Perintah Lisan

Microphone & Voice Recognition.

Gerakan & Visual

Mocap Device, Scanner, Kamera.

🧠 Perangkat Processing

CPU (Processor) — Otak Komputer

  • Central Processing Unit: mengolah semua perintah dan data.
  • Pengolahan Data Biner: mengolah data dalam bentuk bilangan biner (0 dan 1).
  • Kecepatan Proses: menentukan seberapa cepat komputer menjalankan aplikasi.
  • Komponen pendukung: RAM, Power Supply, dan VGA Card.

🖨️ Perangkat Output

🖥️ Monitor

Menampilkan gambar, teks, dan video pada layar.

🖨️ Printer

Mencetak hasil dokumen dan gambar pada kertas.

🔊 Speaker

Mengeluarkan sinyal suara yang diolah oleh sound card.

📽️ Proyektor

Memancarkan tampilan layar ke permukaan dinding atau kain.

💾 Perangkat Penyimpanan

RAM — Volatile

Penyimpanan sementara.

Data hilang/terhapus otomatis saat komputer dimatikan. Digunakan untuk menyimpan data aplikasi yang sedang aktif.

Harddisk, SSD, Flashdisk

Non-Volatile / Penyimpanan permanen.

Data tetap tersimpan meskipun listrik atau komputer padam. Digunakan untuk file, sistem operasi, dan game.

⚙️ Perangkat Lunak

Operating System

Perangkat lunak utama yang mengontrol dan mengelola seluruh sumber daya hardware.

Contoh: Windows, Linux, macOS.

Program Aplikasi

Software khusus yang dibuat untuk membantu pekerjaan spesifik pengguna sehari-hari.

Contoh: Microsoft Word, Web Browser, Game.

👨‍💻 Brainware

Operator / User

Pengguna biasa yang menjalankan aplikasi untuk tugas sehari-hari.

Programmer

Pembuat kode program dan aplikasi perangkat lunak.

System Administrator

Pengelola dan pemelihara keamanan sistem komputer.

🔄 Alur Kerja Sistem Komputer

⌨️

1. Input

Perintah masuk melalui Keyboard / Mouse.

🧠

2. Process

CPU mengolah data biner secara cepat.

💾

🖥️

4. Output
